# Wildlife Wonders — Website Assignment

A three-page wildlife education website built with HTML and CSS.

## Pages
- `index.html` — Home page
- `wildlife.html` — Wildlife facts and conservation tips
- `contact.html` — Contact page with a demonstration form
- `style.css` — Shared design and responsive layout

## Run locally
Open `index.html` in a web browser. Internet access is needed to load the remote wildlife photos and Google Fonts.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload the HTML files, `style.css`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, and save.
5. Wait for GitHub Pages to publish, then open the live URL.

## Before submission
- Check all navigation links and the live site.
- Submit both the live website URL and repository URL.
- Wildlife photos are loaded from Unsplash URLs and need internet access.
- The contact form is a front-end demonstration; it does not send or store messages.
- Avoid publishing private personal contact information.
